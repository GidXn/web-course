# 🧪 Лабораторна робота №1
## Організація середовища веб‑розробки. Створення та публікація веб‑документа

### 📘 Мета роботи
Ознайомитися з базовими інструментами веб‑розробки, налаштувати робоче середовище, створити простий веб‑документ та опублікувати його за допомогою GitHub Pages.

---

### ⚙️ Завдання
1. Встановити Git та налаштувати обліковий запис GitHub.
2. Створити новий репозиторій.
3. Додати базову структуру веб‑документа.
4. Виконати коміти та завантажити проєкт у репозиторій.
5. Опублікувати сторінку через GitHub Pages.
6. Перевірити доступність сторінки за публічним URL.

---

### 🧰 Використане програмне забезпечення
- **Git** — система контролю версій
- **GitHub** — хостинг для репозиторіїв
- **WebStorm** — середовище розробки
