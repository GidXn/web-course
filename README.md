# web-course

Навчальний проєкт: лендінг-сторінка для документаційної платформи, зверстана з макета у HTML і CSS.

## Структура

- `index.html` — розмітка сторінки: шапка з hero, логотипи, картки, блок із AI-чатом, відгуки, фінальний заклик і футер.
- `styles.css` — стилі: кольорові змінні, адаптивна верстка (flexbox і grid), media queries.

## Як переглянути

Відкрий `index.html` у браузері. Для коректного відображення краще запускати через локальний сервер, наприклад:

```bash
python -m http.server 8000
```

і відкрити `http://localhost:8000`.

## Що ще не зроблено

- Фото продукту та іконки-ілюстрації: на їх місці стоять пунктирні блоки з нотатками.
- Повна перевірка на мобільних пристроях.
