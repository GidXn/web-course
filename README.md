## 1. Мета роботи
Опанувати повний цикл створення веб‑документа: розроблення розмітки, використання системи контролю версій Git, розміщення проєкту у віддаленому репозиторії GitHub та публікація сайту через GitHub Pages.

---
## 2. Індивідуальне завдання
Тема наскрізного навчального проєкту: **сайт‑візитка сервісу онлайн‑запису на послуги**.  
Проєкт включає головну сторінку з описом можливостей сервісу, сторінку «Про автора» та базові стилі оформлення.

---
## 3. Хід виконання роботи

### Етап 1. Налаштування середовища
- Вже було встановлено **Visual Studio Code** та **WebStorm**.
- Налаштовано Git, виконано перевірку `git --version`.
- Створено обліковий запис GitHub з двофакторною автентифікацією.

### Етап 2. Створення структури проєкту
Каталог `web-course/` містить:

```
index.html 
about.html 
style.css 
README.md 
.gitignore 
```

### Етап 3. Розроблення сторінок
- **index.html** — головна сторінка з темою проєкту та переліком технологій (HTML, CSS, JavaScript).
- **about.html** — сторінка з відомостями про автора та обґрунтуванням вибору теми проєкту.
- **style.css** — базові стилі: шрифти, кольори, адаптивна верстка.
- **README.md** — опис репозиторію, перелік лабораторних робіт, структура каталогів.
- **.gitignore** — виключення службових файлів (`.DS_Store`, `Thumbs.db`, `.vscode/`, `node_modules/`, `*.log`).

### Етап 4. Контроль версій
- Ініціалізовано локальний репозиторій (`git init`).
- Виконано щонайменше 4 фіксації змін.

### Етап 5. Публікація
- Налаштовано GitHub Pages: **Branch — main, root каталог**.
- Сайт доступний за адресою: [https://gidxn.github.io/web-course](https://gidxn.github.io/web-course).
- Перевірено коректність відображення та роботу посилань.

### Етап 6. Доопрацювання стилю оформлення
- Сторінки `index.html` та `about.html` доповнено семантичними елементами `<header>`, `<main>` та `<footer>` замість самих лише `<div>`.
- У шапці сайту розміщено назву та навігацію (`Головна` / `Про автора`); поточна сторінка підсвічується класом `.active`.
- Верстку шапки виконано за допомогою `flexbox` (властивості `display: flex`, `justify-content: space-between`) — без застарілого позиціювання через `float`.
- У `style.css` введено CSS‑змінні (`:root { --brand-color: ...; }`) для повторного використання кольорів у заголовках, посиланнях, хедері та футері.
- Додано футері сайту з інформацією про авторство.

## 6. Висновки
У ході роботи створено та опубліковано багатосторінковий веб‑документ. Освоєно базові інструменти веб‑розробки (HTML, CSS), систему контролю версій Git та сервіс GitHub Pages. Додатково вдосконалено оформлення сторінок: впроваджено семантичну розмітку (`header`/`main`/`footer`) та верстку на основі `flexbox` замість застарілого `float`. Проєкт відповідає вимогам до структури, оформлення та публікації.
