# Веб-програмування — навчальний проєкт

Репозиторій лабораторних робіт з навчальної дисципліни «Веб-програмування».

**Автор:** Гидін Михайло
**Тема проєкту:** сайт-візитка сервісу онлайн-запису на послуги
**Адреса опублікованого сайту:** https://gidxn.github.io/web-course/

## Перелік лабораторних робіт

- [x] Лабораторна робота № 1 — середовище розроблення, публікація документа
- [ ] Лабораторна робота № 2 — розмітка текстового вмісту

## Використані технології

- HTML5 — структура та змістова розмітка документів
- CSS3 — оформлення та адаптивна верстка
- JavaScript — базова інтерактивність (планується)
- Git / GitHub — контроль версій та публікація через GitHub Pages

## Структура каталогів проєкту

```
web-course/
├── index.html      головна сторінка
├── about.html      сторінка відомостей про автора
├── style.css       базові стилі оформлення (шапка, вміст, підвал)
├── .gitignore      перелік виключень для системи контролю версій
└── README.md       опис репозиторію
```
